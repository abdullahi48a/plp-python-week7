
# Week 7 Assignment: My Notes & The Report Builder

## Files

- my_notes.py: Writes, appends, reads, and counts notes.
- my_notes.txt: Stores the four notes generated by my_notes.py.
- report_builder.py: Reads CSV data and builds a learner report.
- hubs.csv: Contains learner names, hubs, and scores.
- report.txt: Contains the generated learner report.
- README.md: Describes the assignment and its files.

## Reflection

If I changed "a" to "w", the program would erase the first three notes before writing the fourth note. The file would contain only the fourth note instead of all four notes.
